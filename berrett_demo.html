Berrett Pest Control: appointment confirmation and return visits

Concept demo. When a customer books, the system confirms the window by SMS. If the tech runs late, the visit is rescheduled, or the window is missed, it texts the customer automatically instead of leaving them waiting in silence. The return visit under the 4-month agreement is scheduled and confirmed the same way, so it cannot fall out of the system. Missed calls get an automatic reply and a log entry.
